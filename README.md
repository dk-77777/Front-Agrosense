# AgroSense — Visual V8.4 com Configurações V8.5

O visual da Home, Dashboard, Máquinas, Cadastro, Relatórios, sidebar e autenticação foi restaurado para a versão V8.4.

A seção **Configurações** preserva o refinamento visual da V8.5 e as preferências de conta, aparência, notificações e visualização.

Para executar, abra `login.html` pelo Live Server do VS Code ou por um servidor local estático. O Vue e o Three.js da interface utilizam CDNs.

Tecnologias: HTML, CSS, Bootstrap Grid 5, Vue 3, JavaScript, ECharts e Three.js.
